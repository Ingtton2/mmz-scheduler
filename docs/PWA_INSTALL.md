# 홈 화면에 앱 추가하기 (PWA 설치 방법)

memeal.zip 은 앱스토어 설치 없이, 브라우저에서 "홈 화면에 추가"만 하면
휴대폰에 진짜 앱처럼(아이콘 탭 → 바로 실행, 주소창 없이) 설치됩니다.

**사장님용**과 **직원용**은 아이콘과 시작 화면이 서로 다릅니다 — 사장님은
관리자 화면 주소에서, 직원은 직원 로그인 화면 주소에서 각각 설치해야
서로 다른 아이콘이 생깁니다. (같은 주소에서 설치하면 같은 앱이 됩니다.)

| | 사장님용 | 직원용 |
|---|---|---|
| 설치할 주소 | `https://mmz-scheduler.vercel.app/admin` | `https://mmz-scheduler.vercel.app/staff-login` |
| 아이콘 | 로고 + 골드 테두리 | 로고 그대로 |
| 앱 이름 | 메밀집 스케줄 관리 | 메밀집 내 스케줄 |
| 실행하면 열리는 화면 | 관리자 홈 | 직원 로그인 |

---

## 사장님용 설치 방법

### 아이폰 (Safari)
1. Safari 에서 `https://mmz-scheduler.vercel.app/admin` 접속 (로그인은 안 해도 됨)
2. 화면 아래 **공유 버튼**(사각형에 위쪽 화살표) 탭
3. 메뉴를 아래로 스크롤 → **"홈 화면에 추가"** 탭
4. 이름이 "메밀집 스케줄 관리"로 되어 있는지 확인 → 오른쪽 위 **추가** 탭
5. 홈 화면에 골드 테두리가 있는 아이콘이 생깁니다.

### 안드로이드 (Chrome)
1. Chrome 에서 `https://mmz-scheduler.vercel.app/admin` 접속
2. 오른쪽 위 **점 3개 메뉴** 탭
3. **"홈 화면에 추가"** (또는 화면 하단에 뜨는 "앱 설치" 배너) 탭
4. **설치** 탭
5. 홈 화면/앱 서랍에 골드 테두리가 있는 아이콘이 생깁니다.

설치 후 아이콘을 탭하면 브라우저 주소창 없이 바로 관리자 홈 화면이 열립니다.
로그인은 앱 안에서 한 번 하면 (설정한 경우) 유지됩니다.

---

## 직원용 설치 방법

### 아이폰 (Safari)
1. Safari 에서 `https://mmz-scheduler.vercel.app/staff-login` 접속
2. 화면 아래 **공유 버튼** 탭
3. **"홈 화면에 추가"** 탭
4. 이름이 "메밀집 내 스케줄"로 되어 있는지 확인 → **추가** 탭
5. 홈 화면에 로고 아이콘이 생깁니다 (테두리 없음).

### 안드로이드 (Chrome)
1. Chrome 에서 `https://mmz-scheduler.vercel.app/staff-login` 접속
2. **점 3개 메뉴** → **"홈 화면에 추가"** (또는 하단 설치 배너) 탭
3. **설치** 탭
4. 홈 화면/앱 서랍에 로고 아이콘이 생깁니다.

설치 후 아이콘을 탭하면 바로 직원 로그인 화면이 열립니다. 이름 선택 + PIN
입력해서 로그인하면 내 스케줄·연차/사전휴무 신청 화면을 쓸 수 있어요.

## 자주 겪는 문제

| 증상 | 원인 / 해결 |
|---|---|
| "홈 화면에 추가" 메뉴가 안 보임 (아이폰) | 반드시 **Safari** 로 열어야 합니다. 카카오톡 인앱 브라우저 등에서는 이 메뉴가 없어요 — 링크를 받으면 오른쪽 아래 "···" 또는 공유 버튼으로 "Safari로 열기"를 먼저 하세요. |
| 아이콘이 예전 걸로 남아있음 | 한 번 설치한 아이콘은 이름이 같으면 안 바뀔 수 있어요. 기존 아이콘을 삭제하고 다시 설치해보세요. |
| 설치한 앱을 열었는데 화면이 예전 버전 그대로 | 인터넷에 연결된 상태로 한 번 열면 최신 버전이 자동으로 반영됩니다 (자동 업데이트). 그래도 안 바뀌면 앱을 완전히 껐다가 다시 열어보세요. |
| 관리자용이랑 직원용 아이콘이 똑같이 생김 | 설치할 때 주소를 확인하세요 — `/admin` 에서 설치해야 골드 테두리(사장님용), `/staff-login` 에서 설치해야 테두리 없는 로고(직원용)가 됩니다. |
